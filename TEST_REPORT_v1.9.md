# Отчёт о тестировании ScientificGlossary 1.9

Дата: 31.10.2026.

## Стенд

Chromium / Playwright (экран компьютера 1440×920 и мобильная эмуляция 390×844). Контрольный документ: предоставленная пользователем настоящая **12-страничная PDF-статья об электродегидраторе**. Геометрия слов (включая двухколоночное расположение) и исходные предложения получены из этого PDF посредством PyMuPDF.

В браузерных испытаниях **PDF.js заменён тестовым движком** с реальными координатами текста; IndexedDB и сетевой ответ Free Dictionary API имитированы. Доступность MyMemory/Free Dictionary API на Huawei, реальная PDF.js и OCR этой серией **не подтверждены**.

## Проверено (14/14)

1. Импорт 12-страничного PDF и открытие страницы 1.
2. Нажатие на `area` выбирает именно `area`, не соседнее слово.
3. Карточка показывает три локальных значения слова `area` с отдельными учебными примерами и реальным предложением из PDF.
4. Дополнительные определения/примеры по кнопке (имитированный ответ Free Dictionary API).
5. Выбор значения «площадь» и сохранение в глоссарий.
6. Исправление источника со страницы 1 на страницу 2 и сохранение.
7. Экспорт DOCX: OOXML ZIP содержит сохранённое слово, перевод и страницу.
8. На странице 2 слово `water` сохраняет источник как PDF-страницу 2.
9. Ввод несуществующей страницы 9999 блокируется.
10. Выделение мышью `last two decades` без кнопки выбора фразы.
11. Повторное открытие записи сохраняет исправленный номер страницы.
12. Долгое касание `area` в эмулированном мобильном Chromium открывает карточку.
13. Удержание и протягивание пальцем по `last two decades` открывает карточку фразы.
14. Отсутствие исключений JS в этих сценариях; синтаксис встроенного JavaScript и Service Worker проверен Node.js.

**Результат:** 14/14 описанных проверок на стенде, не заменяет приёмочные испытания реального планшета Huawei.

## Ограничения

- При разрыве колонки или структуры статьи выделение длинной фразы ограничено, чтобы не смешивать предложения.
- Некоторые PDF используют нестандартный текстовый слой; для них точность выбора слова может быть ниже.
- Дополнительные примеры в локальной карточке специально составлены и помечены как учебные, **не** цитаты из источника.
- Для подтверждения автономной работы, живого словаря и OCR нужны отдельные тесты на устройстве.
