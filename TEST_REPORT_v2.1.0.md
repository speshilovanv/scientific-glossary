## Регрессия со скриншота

Прежний небольшой словарь не содержал concept, поэтому concepts зависело от MyMemory. В новой поставке concept → «концепция; понятие; представление» находится локально; concepts использует поиск формы слова.

Браузер переводил при полностью отключённой сети: concepts, scheduler, dynamics, hydraulics, pipeline, controllers, specifications, hypotheses, children, running, concept’s. Русское значение найдено для каждого слова. Дополнительно проверены 36 контрольных слов в тесте настоящей базы и набор нерегулярных форм, притяжательных форм и окончаний. Это заданная контрольная выборка, а не измерение полного покрытия английского языка.

## Источник и размер базы

В памяти приложения 57 373 нормализованных слова и выражения: 56 836 ключей производного WikDict/FreeDict TSV плюс прежняя научная база и её дополнения с учётом совпадений. Исходный TEI WikDict/FreeDict 2025.11.23 содержит 62 181 заголовочное слово. Аффиксы, записи без русских значений и совпадения отфильтрованы/объединены. Несколько значений одного слова не считаются отдельными словами.

SHA-512 исходного архива проверяется скриптом scripts/dictionary.py. Поставка включает источник, описание преобразования, атрибуцию Karl Bartel / Wiktionary contributors / DBnary и лицензию CC BY-SA 3.0. Скрипт удаляет ударения и Wiki-разметку. Научные и пользовательские значения имеют приоритет перед общей базой.

## Резервный онлайн-поиск

Если слова нет в локальном словаре или кэше, после ошибки MyMemory выполняется запрос официального MediaWiki API Wiktionary. Извлекаются только русские переводы английского раздела. В отдельном испытании управляемый HTTP 503 MyMemory и контролируемый ответ Wiktionary проверяют переключение источника, ссылку-атрибуцию и последующий поиск сохранённого перевода без сети. Это испытание логики, а не обещание доступности сервиса из любой сети.

Дополнительно внешний настоящий запрос MediaWiki к статье coalescer вернул HTTP 200, русский перевод и заголовок CORS Access-Control-Allow-Origin: *. MyMemory в полном браузерном прогоне также ответил настоящим переводом. В карточке предусмотрена ссылка Google Переводчика, открываемая пользователем для дополнительного слова или фразы.

## Повторная приёмка

- Все прежние сценарии импорта PDF, выделения, контекста, сохранения, фильтров, удаления и восстановления копии.
- Корпус из 15 опубликованных статей: импорт, число страниц, выбор слова, контекст, сохранение и переход на последнюю страницу; не все страницы каждой статьи просматривались.
- Экспорт DOCX, CSV, JSON-копии и печатного PDF.
- Настоящее OCR контрольного английского скана и повторное распознавание после масштаба без сети.
- Мобильная компоновка 390×844, переходы разделов, отсутствие переполнения.
- Повторный перевод сохранённого примера, сброс проверки и сохранение ручных правок при запоздалом ответе.
- Прерванное обновление сохраняет предыдущую офлайн-версию; повторная установка сохраняет четыре хранилища IndexedDB, контрольные байты документа и страницу чтения.
- Синтаксис, уникальность HTML ID, целостность 200 компонентов; общий объём 21 964 125 байт (около 22 МБ).

## Ограничения

Большой словарь не охватывает все имена, неологизмы, термины и произвольные фразы. Автономной модели машинного перевода нет. Качество конкретного значения проверяется по контексту. Работа на физическом Huawei MatePad 11.5 S ещё требует аппаратной приёмки; изменение размера окна Chromium её не заменяет. База IndexedDB остаётся версии 3, пользовательские данные не мигрируют и не удаляются.
