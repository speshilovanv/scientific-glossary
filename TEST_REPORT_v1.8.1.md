# Проверка исправления загрузки PDF — v1.8.1

Дата: 31.10.2026

## Что исправлено

1. Инициализация Service Worker больше не блокирует чтение PDF, если установка/активация кэша зависла.
2. При выборе PDF приложение дожидается PDF.js; если оба внешних источника не отвечают, пробует альтернативу.
3. Если оба источника PDF.js недоступны, реальный PDF **сохраняется в библиотеке** и открывается во встроенном браузерном просмотрщике. В этом режиме выделение английского слова нажатием временно недоступно; термины можно добавить вручную.
4. При следующем успешном подключении PDF.js сохранённый PDF открывается в обычном интерактивном режиме.
5. Критичные ошибки отображаются более конкретно, без необоснованного сообщения о «повреждённом PDF».

### Ограничения

- Интеграционный тест реальной PDF.js на Huawei не проведён, поскольку зависимости CDN недоступны в тестовой среде. PDF.js в стендовом режиме заменялась тестовой реализацией.
- Встроенный просмотр PDF зависит от поддержки браузера; для отдельных версий Android/HarmonyOS возможно открытие документа внешним PDF-приложением.
- OCR, точность онлайн-перевода и синхронизация между устройствами не тестировались в рамках этого исправления.
- Удаление кэша или данных браузера **не требуется** и может повредить вашу библиотеку; сохраните резервную копию глоссария перед действиями с данными сайта.
