# ScientificGlossary Reader 2.2.1

Читалка научных PDF с англо-русским глоссарием для браузеров на компьютере, Android и Huawei.

**Приложение:** https://speshilovanv.github.io/scientific-glossary/

## Работа с приложением

1. Добавьте один или несколько PDF. Документы сохраняются в IndexedDB этого браузера.
2. Нажмите слово. Фразу можно выделить мышью; на сенсорном экране — удержать и провести либо воспользоваться кнопкой «Выделить фразу».
3. Проверьте перевод, пример и номер страницы. Отдельные словарные учебные примеры подписаны и не выдаются за цитаты из PDF.
   Кнопка «Перевести пример онлайн» позволяет заново перевести и сохранённую запись. Правки, введённые во время запроса, имеют приоритет; изменение перевода снимает отметку проверки.
4. Сохраните термин. Поиск, фильтры по документу и проверке помогают подготовить глоссарий.
5. Выгрузите DOCX, CSV или печатную таблицу в PDF. Экспорт учитывает выбранный документ и флажок «только проверенные»; строка поиска и фильтр качества управляют списком на экране.

## Режим чтения и закладки

Кнопка «Режим чтения» скрывает боковую панель, сворачивает дополнительные инструменты и уменьшает верхние панели. По умолчанию включается «Вся страница» — портретный PDF целиком помещается в доступной области. Для более крупного текста выберите «По ширине» или «Крупнее» и прокручивайте страницу. Увеличение/уменьшение масштаба остаётся доступным. Кнопка «⋯» раскрывает перевод, OCR и другие инструменты. «⛶» включает полный экран, если это поддерживает браузер. «Выйти из чтения» возвращает библиотеку.

Нажмите «☆», впишите необязательную заметку и выберите «Сохранить место чтения». Звёздочка становится заполненной для страницы с закладкой. Повторное сохранение на той же странице обновляет её заметку. Список позволяет открыть и удалить закладки.

При следующем запуске автоматически открывается последний документ и выбранная для него закладка: страница, масштаб, вариант подгонки и положение прокрутки. Переход по сохранённой закладке делает её местом возобновления. Просмотр следующих страниц не перемещает закладку; сохраните место снова, когда закончите читать. Без выбранной закладки открывается последняя просмотренная страница. Это работает без сети после завершения установки приложения.

Закладки и заметки хранятся вместе с PDF в этом браузере. Удаление PDF удаляет и его закладки; глоссарий сохраняется. Копия глоссария не содержит PDF и закладки. Повторный импорт того же PDF открывает сохранённую копию с закладками.

## Онлайн и офлайн

В режиме «Авто» выбранное слово или фраза передаются MyMemory; локальное научное значение остаётся основным. Если значения нет локально и MyMemory не ответил, отдельное слово проверяется в Wiktionary через официальный MediaWiki API. Русские значения берутся только из английского раздела; ссылка на источник сохраняется с кэшем. В карточке есть отдельная ссылка Google Переводчика: он открывается только по вашему нажатию. Кнопка «Словарь онлайн» запрашивает английские определения в Free Dictionary API. Предложение отправляется на перевод только по отдельной кнопке. Полный PDF сервисам не передаётся.

Без сети доступны большой локальный словарь (57 373 нормализованных слова и выражения: WikDict/FreeDict плюс научные дополнения) и поиск по формам слов, импортированные TSV, сохранённые значения и кэш онлайн-переводов. Например, `concepts` ищется как `concept` и переводится «концепция; понятие; представление» без сети. Для отсутствующего термина доступны онлайн-поиск, внешний переводчик и ручной ввод. Полного покрытия всех английских слов, имён, новых терминов и произвольных фраз не гарантируется. **Это словарный офлайн-поиск, а не переводчик произвольного текста.** Доступность и точность внешних сервисов не гарантируются.

PDF.js, шрифты, Tesseract и английская модель OCR входят в поставку. После первого открытия дождитесь надписи **«готово без сети»**: установка сохраняет около 22 МБ компонентов. Затем можно перезагрузить приложение без интернета, открыть сохранённые или добавить новые PDF и распознавать английские сканы. OCR выполняется на устройстве; формулы и сложные колонки требуют ручной проверки. Сброс кэша браузером потребует повторной загрузки приложения.

## Данные и резервная копия

- Существующая база `scientific-glossary-web`, версия 3, сохраняется; обновление не удаляет статьи и записи.
- JSON-копия версии 2 включает глоссарий, пользовательский словарь и кэш переводов. **Сами PDF не входят** — храните оригиналы отдельно.
- Копии версии 1 поддерживаются. Восстановление не затирает свежую локальную запись: конфликтующая версия добавляется отдельно. Полностью одинаковые записи с тем же ID пропускаются.
- Удаление PDF оставляет глоссарий. Синхронизации между устройствами нет.
- Не очищайте данные сайта без резервной копии.

## Разработка и проверка

Поставка работает как статический сайт из `main` / корень. Замены только `index.html` теперь **недостаточно**: нужна также папка `vendor` и новый `sw.js`.

```sh
npm ci --ignore-scripts --omit=optional
npm run check
npx playwright install --with-deps chromium
node tests/download-papers.mjs
npm test
```

`npm run vendor` воспроизводит локальные компоненты из закреплённых npm-пакетов. При отсутствии английской модели скрипт загружает официальный пакет `@tesseract.js-data/eng@1.0.0`. `vendor/manifest.json` содержит версии, размеры и SHA-256 компонентов. PDF.js и Tesseract распространяются по Apache-2.0; тексты лицензий входят в `vendor`.

GitHub Actions сохраняет результаты, экспортированные документы и снимки интерфейса в `acceptance-results`. Источники 15 опубликованных статей перечислены в `tests/papers.json`; это корпус для технической проверки, а не тематическая экспертиза нефтегазовой терминологии.

Аппаратную приёмку на Huawei MatePad 11.5 S необходимо провести на самом устройстве: браузерная эмуляция не подтверждает поведение HarmonyOS.

## Источник большого словаря

WikDict / FreeDict English–Russian 2025.11.23, Karl Bartel; исходные данные участников Wiktionary через DBnary. Исходный TEI содержит 62 181 заголовочное слово; после отбора русских значений, исключения аффиксов, объединения совпадений и добавления прежней научной базы в памяти приложения 57 373 ключа. Множественные значения не считаются отдельными словами. Это размер базы, а не процент покрытия языка.

Адаптация TSV распространяется по CC BY-SA 3.0; источник, описание преобразования и текст лицензии находятся в `vendor/dictionary/`. Скрипт `python3 scripts/dictionary.py` скачивает закреплённый архив, проверяет SHA-512 и воспроизводит данные. После изменения данных запустите `npm run vendor`, чтобы пересчитать офлайн-манифест. Научные дополнения и пользовательские значения имеют приоритет перед общей базой.
