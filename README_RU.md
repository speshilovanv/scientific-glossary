# ScientificGlossary Web — первая браузерная версия

Веб-приложение для чтения англоязычных PDF, сохранения терминов в локальный глоссарий и экспорта списка.

## Что есть в прототипе

- Адаптивный интерфейс для планшета, телефона и компьютера.
- Импорт PDF в локальную библиотеку браузера (IndexedDB).
- Отображение оригинальной страницы PDF через PDF.js: иллюстрации, таблицы и формулы остаются частью страницы.
- Текстовый слой для PDF, в которых есть выделяемый текст; можно нажать на слово или выделить фразу.
- Встроенный англо-русский словарь научной и нефтегазовой терминологии (стартовый словарь, не машинный переводчик).
- Ручное исправление перевода и примера из текущей страницы.
- Сохранение глоссария локально на устройстве.
- Экспорт CSV, Word-совместимого HTML-документа с расширением .doc и печать/сохранение в PDF через браузер.
- PWA-манифест и Service Worker для кэширования оболочки и библиотек после первого онлайн-запуска.

## Важные ограничения первой версии

1. **Сканированные PDF:** страница со сканом отображается как оригинал, но распознавание OCR ещё не включено. OCR — следующий модуль; английскую OCR-модель нужно будет один раз загрузить и сохранить на устройстве.
2. **Офлайн-перевод:** встроенный словарь работает локально, но это не полноценный нейронный переводчик. Незнакомое слово можно добавить вручную.
3. **Первый запуск:** PDF.js загружается с CDN. Поэтому при первом открытии опубликованной версии нужен интернет. Service Worker затем кэширует оболочку и внешние JS-файлы; фактическую офлайн-работу следует проверить на конкретном браузере.
4. **Word:** файл .doc содержит HTML-таблицу, совместимую с Microsoft Word. Настоящий .docx будет добавлен отдельным этапом.
5. **Хранилище:** PDF и глоссарий сохраняются в IndexedDB конкретного браузера и устройства. Очистка данных браузера может удалить их — периодически экспортируйте глоссарий.
6. В этой среде нельзя опубликовать приложение на постоянном HTTPS-адресе от имени пользователя. ZIP — исходный комплект для размещения на HTTPS-хостинге.

## Как открыть для проверки

### На компьютере

Из папки проекта запустите локальный сервер, например:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Для установки PWA и Service Worker нужен HTTPS или localhost.

### На Huawei MatePad / Android

Для постоянной установки как веб-приложения файлы нужно разместить на HTTPS-хостинге (например, GitHub Pages). После публикации откройте адрес в браузере и выберите «Добавить на главный экран» / «Установить приложение».

Просто открыть `index.html` из ZIP можно для ограниченного теста, но Service Worker и установка PWA через `file://` не работают.

## Публикация на HTTPS

## Состав

- `index.html` — интерфейс приложения
- `styles.css` — адаптивное оформление
- `app.js` — PDF.js, локальная БД, словарь, карточки и экспорт
- `sw.js` — Service Worker
- `manifest.webmanifest` — PWA-манифест
- `assets/dictionary.tsv` — стартовый локальный словарь
- `assets/icon.svg` — иконка
