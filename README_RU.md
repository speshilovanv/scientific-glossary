# ScientificGlossary Reader v1.8

Браузерная читалка научно-технических PDF для Android, Huawei и компьютеров. Сохраняет исходное изображение страницы, позволяет нажать на слово, получить варианты перевода, выбрать пример **из PDF** и сохранить запись в глоссарий.

## Запуск

GitHub Pages: https://speshilovanv.github.io/scientific-glossary/

Основной файл `index.html` включает код интерфейса, логику приложения, экспорт DOCX и базовый словарь. Отдельная сборка не нужна.

## Новое в 1.8
- Прямой переход к странице PDF (удобно в больших учебниках).
- Фильтры глоссария «Нужно проверить», «Нет примера», «Проверено».
- Редактирование английского предложения автоматически снимает отметку «Проверено» до повторной проверки.
- Обновлённый Service Worker: кэширование одностраничной версии, а не устаревших исходников.
- Сохранённая совместимость со старой базой IndexedDB (`scientific-glossary-web`, версия 3); нет миграции и удаления данных.

## Использование
1. Нажмите «Добавить PDF», выберите статью или пособие.
2. Нажмите на английское слово (для фразы используйте отдельный режим).
3. Проверьте перевод и пример **по оригинальной статье**.
4. Сохраните термин. Для зачёта воспользуйтесь фильтром проверки и экспортом в DOCX, CSV или печать в PDF.
5. Периодически скачивайте JSON-резервную копию глоссария. **В неё не включены сами PDF.**

## Перевод и ограничения
- Встроенный англо-русский словарь и сохранённые переводы работают без интернета.
- Режим «Авто» запрашивает варианты слов через MyMemory; сервис может быть недоступен или ошибаться в техническом контексте.
- PDF.js загружается извне при первом запуске. Для доступности офлайн браузер должен успешно сохранить библиотеку и её рабочий файл.
- Для сканов предусмотрен экспериментальный OCR; достоверность распознавания формул/многоколонного текста не гарантирована.
- Данные хранятся в данном браузере. Синхронизация между устройствами отсутствует.
- Результаты автоматических проверок и ограничения см. в `TEST_REPORT_v1.8.md`.

Вкладка GitHub Pages использует `main` / `/(root)`. Обновляйте код через проверенную ветку/PR. Не очищайте данные сайта без резервной копии глоссария. Изменения интерфейса не должны удалять IndexedDB.
