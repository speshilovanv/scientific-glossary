# Публикация ScientificGlossary 2.3.1

Рабочий адрес: https://speshilovanv.github.io/scientific-glossary/

GitHub Pages публикует ветку `main`, папку `/ (root)`. После успешных проверок обновление выпускается слиянием release-ветки. Поставка включает `index.html`, `sw.js`, `manifest.webmanifest`, `assets` и всю папку `vendor`.

Для ручной установки используйте весь исходный ZIP актуальной версии из GitHub. Загрузка одного `index.html` больше не подходит.

После публикации откройте приложение онлайн, обновите страницу и проверьте версию **v2.3.1**. Дождитесь **«готово без сети»**, затем проверьте повторное открытие в авиарежиме. Кэширование всех компонентов занимает около 22 МБ.

Старые PDF и глоссарий остаются в IndexedDB, версия базы не меняется. Не очищайте данные сайта ради обновления. Перед обновлением полезно скачать JSON-копию слов; оригиналы PDF храните отдельно.

Service Worker устанавливает новую версию только после загрузки всех локальных компонентов. Если установка оборвалась, прежняя версия остаётся активной. Повторите открытие онлайн; при обновлении уже открытой вкладки может потребоваться ещё одна обычная перезагрузка страницы.

В 2.3.1 новая версия кэша включает компактный режим чтения и закладки. База IndexedDB остаётся версии 3; закладки записываются в существующую запись PDF. Для автоматического продолжения один раз откройте нужный документ или сохраните закладку.
