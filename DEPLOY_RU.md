# Как разместить ScientificGlossary Web в интернете

Для установки как веб-приложения на Huawei/Android нужен HTTPS-адрес. Один раз разместите папку `ScientificGlossaryWeb` на статическом хостинге.

## Простой вариант — GitHub Pages

1. В браузере откройте https://github.com и войдите или создайте бесплатную учётную запись.
2. Создайте новый публичный репозиторий, например `scientific-glossary`.
3. Загрузите **содержимое** папки `ScientificGlossaryWeb` в корень репозитория (не сам ZIP как один файл).
4. Откройте `Settings` → `Pages`.
5. В разделе `Build and deployment` выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`, затем `Save`.
6. После публикации GitHub покажет адрес вида `https://ВАШ-ЛОГИН.github.io/scientific-glossary/`.
7. Откройте адрес на Huawei MatePad в браузере. В меню браузера выберите `Добавить на главный экран` или `Установить приложение`.

## Важно

- При первом открытии нужен интернет, чтобы загрузить PDF.js. Service Worker должен закэшировать оболочку и PDF.js для последующих запусков.
- После установки откройте приложение ещё раз онлайн, затем включите авиарежим и проверьте запуск. Офлайн-поведение браузеров отличается, поэтому его нужно проверить на самом планшете.
- Не очищайте данные сайта в браузере: там хранятся ваши PDF и глоссарий.
- Экспортируйте CSV/Word регулярно как резервную копию.
