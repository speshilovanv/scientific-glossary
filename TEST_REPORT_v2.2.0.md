# Проверка ScientificGlossary Reader 2.2.0

Дата: 31.10.2026. Стенд: GitHub Actions, Node.js 22, Chromium 151 / Playwright 1.62.1.

[Первый успешный прогон кода и тестов](https://github.com/speshilovanv/scientific-glossary/actions/runs/41208214714). Commit: `c51edcb937a8b497ebe0212cb3ee7cc3b10714cb`.

Пройдены 13 верхнеуровневых тестов: прежняя браузерная приёмка (21 группа), отдельный сценарий режима чтения/закладок (5 групп), 10 точечных тестов переводов и сценарий прерванного обновления. Необработанных ошибок JavaScript в браузерных сценариях нет.

[Артефакт acceptance-results](https://github.com/speshilovanv/scientific-glossary/actions/runs/41208214714/artifacts/13044689013) содержит reader.json, снимки режима чтения на планшете/телефоне, окно заметки, результаты PDF, экспорта и OCR.

## Новые сценарии

1. Экран 1024×550: область чтения занимает более 75% доступной высоты окна, PDF целиком помещается по обеим осям в режиме «Вся страница», инструменты свёрнуты.
2. В режиме «По ширине» доступны верхний и нижний края страницы. Дополнительные инструменты раскрываются и скрываются явно.
3. Закладка на странице 2 сохраняется с русской заметкой, масштабом 115% и прокруткой 40%. После перехода на страницу 3 и перезагрузки без сети автоматически открываются прежний PDF и закладка на странице 2 с тем же положением и масштабом. Правка заметки не создаёт дубликат.
4. Повторный импорт того же PDF сохраняет заметки. Добавление второй закладки, выбор первой, удаление выбранной и возврат к оставшейся проверены. После удаления всех закладок перезагрузка восстанавливает последнюю просмотренную страницу.
5. Экран 390×844: режим целой страницы помещает PDF без горизонтального переполнения.

Снимки всех трёх новых представлений просмотрены отдельно. После первого прогона дополнительно уточнён статус сохранения заметки, статическая проверка новых элементов интерфейса и ожидание скрытия временного уведомления перед снимками.

## Повторная приёмка

Все 15 опубликованных PDF из tests/papers.json открылись; проверены число страниц, выбор слова, контекст, сохранение и переход на последнюю страницу. Это не просмотр всех страниц каждой статьи. Также повторно проверены экспорт DOCX/CSV/JSON/печать PDF, восстановление слов, словарь 57 373 ключей, офлайн-переводы, настоящие PDF.js/IndexedDB/OCR, обработка неудачной транзакции и прерванное обновление с сохранением четырёх хранилищ. SHA-256 200 компонентов совпадают.

## Границы

Размеры окна Chromium не заменяют физическую проверку Huawei/Yandex Browser. Полноэкранный режим зависит от браузера и запускается пользователем; интерфейс не может самостоятельно скрыть системные панели. Заметки и закладки хранятся в записи локального PDF, не синхронизируются между устройствами и не входят в копию глоссария. Изменения схемы базы и удаления пользовательских данных при обновлении нет.
