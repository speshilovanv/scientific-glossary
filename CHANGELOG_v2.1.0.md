# ScientificGlossary Reader 2.1.0

31.10.2026

- Локальная англо-русская база расширена с примерно 1 300 исходных записей до 57 373 нормализованных слов и выражений с научными дополнениями.
- Подключена закреплённая редакция WikDict / FreeDict 2025.11.23. Данные преобразуются воспроизводимым скриптом с проверкой SHA-512; атрибуция и лицензия CC BY-SA 3.0 включены в поставку.
- `concepts` переводится без сети через `concept`: «концепция; понятие; представление». Добавлены притяжательные формы, нерегулярные множественные числа и глаголы, степени сравнения, дополнительные окончания.
- Для отсутствующего локально отдельного слова после отказа MyMemory проверяется русский перевод в английском разделе Wiktionary. Результат и источник сохраняются для офлайн-повтора и резервной копии.
- Добавлена явная ссылка Google Переводчика для дополнительных слов и фраз. Она открывается пользователем; приложение не отправляет туда PDF.
- Локальные научные и пользовательские значения сохраняют приоритет. Офлайн-перевод не выдаётся за полную модель машинного перевода.
- В офлайн-поставке 200 компонентов, около 22 МБ. Изменён идентификатор кэша. Версия IndexedDB остаётся 3.
- Добавлены тесты слов со скриншота, форм слов, приоритета пользовательского перевода, резервного источника, атрибуции и использования сохранённого значения без сети.

База не охватывает все имена собственные, новые и редкие слова либо произвольные фразы. Качество выбранного значения необходимо проверять по контексту.
