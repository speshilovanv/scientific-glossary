# Проверка ScientificGlossary Reader 2.0

Дата: 31.10.2026. Стенд: GitHub Actions, Ubuntu 24.04, Node.js 22, Chromium 151 / Playwright 1.62.1. Экраны 1440×1000 и 390×844.

**Результат: 18 из 18 сценариев стенда пройдены (100%). Необработанных ошибок JavaScript нет.**

[Полный успешный прогон GitHub Actions](https://github.com/speshilovanv/scientific-glossary/actions/runs/41174382088). Проверенный commit: `35fa2acfa8a4c3554b08af51164fd6a7a8134bcc`. В артефакте `acceptance-results` находятся результаты по статьям, снимки интерфейса, DOCX/CSV/печатный PDF и резервная копия.

## Что проверялось

Браузер открывал настоящий статический сайт. PDF.js 4.10.38, его worker, IndexedDB и Tesseract.js 7.0.0 работали без подмен. OCR проверялся на контрольном PDF с растровым изображением английского предложения, созданном специально для теста. Это подтверждает запуск и работу настоящего движка, а не точность OCR на всех сканах.

MyMemory проверен живым браузерным запросом: сервис ответил, локальное научное значение сохранило приоритет. Для воспроизводимого испытания HTTP 503 и интерфейса английского словаря/перевода предложения используются отдельно обозначенные управляемые ответы API. Это не проверка доступности Free Dictionary API на Huawei.

На каждой из 15 опубликованных статей проверены импорт, реальное число страниц, выбор слова по геометрии PDF, извлечение контекста, сохранение термина и открытие последней страницы. В корпусе **353 страницы**; утверждение о просмотре всех 353 страниц или проверке всех слов не делается. Это статьи по машинному обучению с различной вёрсткой, формулами, таблицами и рисунками; качество нефтегазовых переводов ими не оценивается.

## Сценарии приёмки

1. Импорт настоящего PDF и сохранение бинарных данных.
2. Выбор слова, локальный перевод, подлинный контекст и проверенная запись.
3. Отмена транзакции IndexedDB: редактор и исходная запись сохраняются.
4. Выделение фразы мышью.
5. Переход к странице, отклонение неверной страницы, масштабирование и проверка страницы источника.
6. Защита от дубликата PDF и сохранение данных после перезагрузки.
7. Экспорт DOCX, CSV, JSON-копии v2 и печатного PDF.
8. Восстановление копии без потери текущих правок, обработка некорректных строк.
9. Импорт TSV и немедленный локальный поиск.
10. Живой MyMemory либо корректное сообщение о резервном локальном переводе.
11. Управляемая ошибка HTTP 503: сохранение доступности локального значения.
12. Ручной ввод, несколько значений, запрет проверки без примера, экспорт только проверенных и удаление термина.
13. Переход к источнику, фильтр документа, клавиатура и режим чтения.
14. Английские определения и перевод предложения не подменяют оригинальный английский пример.
15. Корпус из 15 опубликованных PDF.
16. Офлайн-перезагрузка, импорт нового PDF, настоящее OCR и повторное OCR после масштаба.
17. Мобильная компоновка и навигация между разделами, отсутствие переполнения страницы.
18. Удаление открытого PDF сохраняет глоссарий и отключает навигацию.

Дополнительно проверены синтаксис JS, уникальность HTML ID и SHA-256 всех 196 локальных компонентов. `npm audit --omit=optional` на дату проверки: известных уязвимостей не обнаружено. Экспортированный DOCX отдельно проверен на CRC ZIP, XML, английский/русский текст и источник; печатный PDF открыт и визуально просмотрен.

## Ограничения и оставшаяся приёмка

19. Проверка непосредственно на Huawei MatePad 11.5 S: запуск установленного PWA, сенсорное удержание/протягивание, поведение браузера и памяти при больших PDF. Физического устройства на стенде нет. Изменение размера окна Chromium не заменяет аппаратную приёмку.

Словарный офлайн-поиск не переводит произвольный текст. Встроено 1318 исходных записей и научные дополнения; доступны TSV, сохранённые значения, кэш онлайн-переводов и ручной ввод. Качество машинного перевода и OCR необходимо сверять с оригиналом.

Резервная копия не включает сами PDF. Данные остаются в конкретном браузере. Первое получение приложения и установка полного кэша требуют сети; после надписи «готово без сети» чтение и OCR доступны автономно.

Проценты готовности относятся только к этому явно заданному списку из 19 пунктов: успешные 18 сценариев стенда — 94,7%, аппаратная приёмка — оставшиеся 5,3%. Это не процент отсутствующих ошибок и не гарантия совместимости со всеми PDF.
